# Конструктор Резюме 📄✨

Это веб-приложение для создания профессиональных резюме с современным дизайном. Пользователи могут заполнить форму, загрузить и обрезать фото, а затем скачать готовое резюме в формате PDF или PNG.

## 🚀 Основные возможности

- **Мультиязычность**: Интерфейс на русском и узбекском языках.
- **Загрузка и обрезка фото**: Интерактивный редактор для подготовки идеального фото.
- **Генерация PDF и PNG**: Скачивание резюме в двух популярных форматах.
- **Современный дизайн**: Чистый и профессиональный шаблон для итогового документа.
- **Серверная генерация**: Используется Puppeteer для точного рендеринга HTML в файлы.

## 🛠️ Технологии

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS), Croppie.js
- **Backend**: Node.js, Express.js
- **Генерация документов**: Puppeteer
- **Обработка форм**: Multer

## ⚙️ Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/ВАШ_НИК/resume-builder.git
    cd resume-builder
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Запустите сервер:**
    ```bash
    npm start
    ```

5.  Откройте браузер и перейдите по адресу `http://localhost:3000`.
